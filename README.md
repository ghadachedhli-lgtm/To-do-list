# 📝 To-Do List

A small, cute to-do list app styled like a sticky note, built with React (JavaScript) and Bootstrap. The design comes from a Figma notebook-paper layout.

## Features
- Add tasks with the Add button or the Enter key
- Check a task off to strike it through
- Delete tasks you no longer need
- Pastel green underline on each task and a responsive centered layout

## Tech stack
React · JavaScript · Bootstrap 5 · CSS

## Getting started
```bash
npm install
npm run dev   # or: npm start
```
